# Iris Machine Learning Project

## Overview
A beginner machine-learning project that classifies Iris flowers using their measurements.

## Dataset
The Iris dataset contains four features:
- Sepal length
- Sepal width
- Petal length
- Petal width

The target variable is the flower species.

## Machine Learning Algorithms
- Decision Tree Classifier
- Random Forest Classifier
- K-Nearest Neighbors (KNN)

## Tools and Libraries
- Python
- Google Colab
- Pandas
- Scikit-learn
- Joblib

## Evaluation Methods
- Accuracy score
- Confusion matrix
- Precision, recall, and F1-score
- Five-fold cross-validation

## Learning Objectives
Practice loading a CSV dataset, cleaning data, splitting features and targets, scaling numerical features, training models, and evaluating their performance.
